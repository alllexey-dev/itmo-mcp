# Каталоги

| Файл | Что внутри |
|---|---|
| `web-api-calls.tsv` | Все вызовы API из JS-бандлов my.itmo.ru (Nuxt, 135 чанков): раздел, метод, путь. Имена переменных в `{...}` восстановлены из минифицированного кода и условны; часть путей, собранных по частям, обрезана |

Каталог описывает то, что есть в веб-клиенте, а не то, что доступно студенту: многие разделы (`constructor`,
`constructor-ep`, `gia`, `vacation`, `employments`) предназначены для сотрудников и администраторов. Как каталог
получен, описано в [../sources.md](../sources.md).
