# Спецификации

Проверенные спецификации лежат в корне репозитория и используются для генерации клиента:

| Файл | Что описывает | Как проверяется |
|---|---|---|
| [`../../openapi/my-itmo.yaml`](../../openapi/my-itmo.yaml) | my.itmo.ru: расписание, зачётка, учебный план, люди, физкультура, финансы, общежитие, бронирование, заявки и другое | Все GET-операции сверяются с живыми ответами (`npm run verify:live`); пишущие операции проверены вручную, см. документы сервисов |
| [`../../openapi/bars.yaml`](../../openapi/bars.yaml) | БАРС: пользователь, дисциплины, журнал студента | `npm run verify:live` |

Исследовательские спецификации в этой папке:

| Файл | Что описывает | Как проверяется |
|---|---|---|
| [`my-itmo-extra.yaml`](my-itmo-extra.yaml) | Дополнительные ручки my.itmo.ru: физкультура (отборы, проекты, экстернат, инструктажи, лимиты), навигатор, активности человека, заявки v2, общежитие, меню портала, статусы выбора, справочники бронирования, очереди | Схемы выведены из живых ответов и кода сайта; примеры проверяются тем же скриптом |
| [`bars-extra.yaml`](bars-extra.yaml) | Дополнительные студенческие ручки БАРС: дедлайны, личные настройки, планы контрольных точек, история оценок | Ответы сняты вживую; где пусто - модель из кода БАРС |
| [`itmo-services.yaml`](itmo-services.yaml) | Бэкенды вне прокси my.itmo.ru: загруженность помещений, расписание преподавателя, история зачётки, события и оценки, "Актуальное", клубы, достижения, помощь, обходной лист | Ответы сняты вживую и совпали со схемой; обезличенные примеры в [`examples/`](examples/) проверяет `npx tsx research/tools/validate-examples.ts` |

Бэкенды из `itmo-services.yaml` принимают тот же токен ITMO.ID, что и my.itmo.ru. Где ответ на проверочном
аккаунте был пустым, модель взята из кода клиента: в схеме это помечено "Observed empty". В itmo-mcp они не используются.

Ручки, которых нет в этих файлах, описаны в документах [../services/](../services/) таблицами со статусами.
Перед добавлением ручки в спецификацию её ответ нужно снять вживую, обезличить
(`scripts/sanitize-fixture.ts`) и добавить фикстуру в тесты.
